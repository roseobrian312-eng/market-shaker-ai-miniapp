MARKET SHAKER AI V3 — START HERE

FOR YOUR TELEGRAM MINI APP:
1. Extract this ZIP.
2. Open your EXISTING GitHub repo: market-shaker-ai-miniapp.
3. Upload the contents of THIS folder, including public, netlify, extension, and the root files.
4. Commit to main. Wait for Netlify to publish. Your bot @OptionChappaBot remains the same.
5. In Netlify, make sure OTCHARTS_API_KEY and SCANNER_ACCESS_CODE are set privately, with Functions scope.
6. Open https://market-shaker-ai-miniapp.netlify.app/ and verify you see the AI Model Research and Recorded trade results sections.

FOR THE CHROME FLOATING WIDGET ON WINDOWS:
1. In Chrome open: chrome://extensions
2. Switch Developer mode ON.
3. Click Load unpacked.
4. Select the 'extension' FOLDER from this extracted project.
5. Open its Extension options and save your private SCANNER_ACCESS_CODE (the same value as Netlify).
6. Open Pocket Option in Chrome and refresh that tab; the Market Shaker AI panel will appear.
7. Use Scan only when needed (normally 1 OTCharts API request per click).
8. Use Saved to re-run the same data without new API usage.

RESTRICTIONS:
- This release does NOT execute trades automatically.
- This release does NOT contain a validated high-win-rate AI model. The Strategy Lab has a real but RESEARCH-ONLY trained logistic model; live alerts remain rule-based.
- User-marked wins/losses are NOT independently verified against broker history.
- Telegram and the Chrome extension share strategy/data API, but not instant session synchronization or outcome counters.
- NEVER paste a secret API key or passcode into GitHub or chat messages.
